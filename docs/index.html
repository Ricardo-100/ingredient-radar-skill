01 / 提供标签

目标由你选择

提供食品包装照片，明确选择增肌、减脂控糖或生酮，并声明关注的过敏原。

02 / 换算份量

看懂每次吃多少

同时保留每 100 g 与每份口径。演示样例为 60 g 整包，糖 19.4 g、能量 280 kcal。

03 / 回看依据

结论对应原文

保留标签文字和定位区域；看不清的字段提示复核，帮助你核对判断来源。

关于本次演示

对话画面为 Agent 操作流程示意，项目当前形态为 Skill。数字和结果图来自仓库合成标签及已有抽取记录的实际脚本回放；本视频不表示重新识别新照片或已发布独立 App。

本项目用于配料与营养信息的规则比对，不替代医疗或专业营养建议。过敏相关结论请人工核对原包装。
